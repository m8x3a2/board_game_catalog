# Пояснение запуска и результата проверок

## Как запускать проект

Откройте PowerShell в папке проекта и активируйте виртуальное окружение:

```powershell
venv\Scripts\activate
```

Если слева в строке появилось `(venv)`, окружение активировано. Оно содержит
установленные инструменты `pytest` и `flake8` и не требует переустановки.

Запуск программы:

```powershell
python main.py
```

Запуск тестов:

```powershell
pytest -v
```

Проверка стиля кода:

```powershell
flake8 .
```

Чтобы выйти из окружения, используется команда:

```powershell
deactivate
```

## Что означает вывод pytest

Строка `collected 5 items` означает, что pytest нашёл пять автоматических
тестов в папке `tests`.

Каждая строка со словом `PASSED` означает успешное выполнение одного теста.
Например, тесты проверяют расчёт среднего рейтинга, строковое представление
классов, поиск и сортировку игр, проверку оценки от 0 до 10 и сохранение
данных каталога.

Итоговая строка:

```text
5 passed in 0.03s
```

означает, что все пять тестов успешно завершились примерно за 0,03 секунды.
Ошибок в тестируемой программе не обнаружено.

## Что означает отсутствие вывода flake8

Команда `flake8 .` проверяет оформление Python-кода: длину строк, отступы,
неиспользуемые импорты и другие правила PEP 8. Если после команды ничего не
выводится, это хороший результат: flake8 не обнаружил замечаний.

## Кратко о ПР2

В ПР2 первоначальная программа из одного файла была расширена:

- данные о категориях, играх, пользователях и оценках хранятся в JSON-файлах;
- программа разделена на модули по назначению;
- добавлены поиск и сортировка игр;
- добавлена оценка игры числом от 0 до 10;
- добавлена обработка некорректного ввода;
- добавлены автоматические тесты и проверка flake8.

## Кратко о ПР3

В ПР3 программа была преобразована в объектно-ориентированную:

- созданы классы `Category`, `Game`, `User` и `Rating`;
- у классов есть атрибуты, конструктор `__init__` и метод `__str__`;
- класс `Game` рассчитывает средний рейтинг, метку качества и выводит карточку
  игры;
- данные из JSON при загрузке превращаются в объекты классов;
- при сохранении объекты снова преобразуются в данные JSON;
- тесты адаптированы к классам и успешно проходят.

## Кратко о программе

Программа называется «Каталог настольных игр». В ней можно просмотреть список
игр, найти игру по части названия и добавить оценку с коротким отзывом.

В каталоге есть четыре основные сущности:

- `Category` - категория или жанр игры;
- `Game` - игра, её название, категория и год выпуска;
- `User` - пользователь, оставляющий оценку;
- `Rating` - оценка от 0 до 10 и комментарий пользователя.

Данные лежат в папке `data`: отдельные JSON-файлы хранят категории, игры,
пользователей и оценки. При выходе из программы через пункт `0` новые оценки
сохраняются в файл `data/ratings.json`.
