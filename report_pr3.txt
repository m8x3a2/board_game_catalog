ПРАКТИЧЕСКАЯ РАБОТА № 3
Тема индивидуального проекта: «Каталог настольных игр»

Цель работы
Переработать функциональную программу ПР2 в объектно-ориентированную модель.

Выполненная доработка проекта
Основные сущности предметной области представлены классами Category, Game,
User и Rating. Каждый класс имеет атрибуты, конструктор __init__ (создаётся
декоратором @dataclass) и строковое представление __str__.

Класс Game содержит методы average_rating(), rating_label() и card(). Он
взаимодействует с объектами Rating: оценки связываются с игрой по game_id,
а также с пользователем по user_id. Коллекции приложения хранят объекты
классов. При загрузке из JSON словари преобразуются в объекты, а при
сохранении объекты преобразуются обратно в словари.

Сохранены функции ПР2: поиск и сортировка игр, создание оценок, проверка
диапазона от 0 до 10, обработка ошибок и JSON-хранение. Добавлены тесты
создания объектов, строковых представлений, среднего рейтинга и работы JSON.

Проверка результата
Тесты запускаются командой pytest -v. Проверка оформления выполняется
командой flake8 . .

Вывод
В результате ПР3 проект получил простую объектную модель. Данные и поведение
объединены в классах, при этом основная функциональность ПР2 сохранена.
