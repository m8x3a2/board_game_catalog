# Каталог настольных игр

## Назначение
Приложение предназначено для ведения каталога настольных игр: хранения информации об играх, их категориях, а также оценок и отзывов пользователей. В перспективе приложение развивается в полноценный веб-сервис на Django с базой данных, пользователями и REST API.

## Целевая аудитория
Любители настольных игр, которые хотят вести учёт игр в своей коллекции, оставлять оценки и отзывы, а также находить игры по категориям перед покупкой или игровым вечером.

## Предметная область
Предметная область — каталогизация настольных игр и пользовательских оценок. Каждая игра относится к одной или нескольким категориям (жанрам) и может получать оценки и текстовые отзывы от зарегистрированных пользователей.

## Основные сущности
- **Игра** — название, категория, дата выхода, список оценок.
- **Категория** — название и краткое описание жанра игры (например, «Стратегия», «Семейная игра»).
- **Пользователь** — имя, список оставленных оценок и отзывов.
- **Оценка** — числовое значение, текст отзыва, автор и игра, к которой относится оценка.

## Основные функции

- поиск и сортировка игр;
- добавление оценки от 0 до 10;
- расчёт среднего рейтинга и текстовой метки качества;
- вывод карточки игры;
- загрузка и сохранение данных в JSON;
- обработка ошибочных данных пользователя.

## Классы ПР3

- `Category` — жанр игры;
- `Game` — игра, её категория и год выпуска;
- `User` — пользователь каталога;
- `Rating` — оценка и отзыв пользователя об игре.

`Game` рассчитывает среднюю оценку по объектам `Rating`. В JSON-файле связи
оценки с игрой и пользователем хранятся через `game_id` и `user_id`.

## Структура

```text
board_game_catalog/
├── main.py            # меню приложения
├── models.py          # классы предметной области
├── categories.py      # операции с категориями
├── games.py           # поиск и сортировка игр
├── users.py           # операции с пользователями
├── ratings.py         # создание и проверка оценок
├── storage.py         # JSON-загрузка и сохранение
├── data/              # данные каталога
└── tests/             # автоматические тесты
```
