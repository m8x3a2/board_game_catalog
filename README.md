# Каталог настольных игр

## Назначение
Приложение предназначено для ведения каталога настольных игр: хранения информации об играх, их категориях, а также отзывов пользователей с числовой оценкой от 0 до 10. В перспективе приложение развивается в полноценный веб-сервис на Django с базой данных, пользователями и REST API.

## Целевая аудитория
Любители настольных игр, которые хотят вести учёт игр в своей коллекции, оставлять оценки и отзывы, а также находить игры по категориям перед покупкой или игровым вечером.

## Предметная область
Предметная область — каталогизация настольных игр и пользовательских отзывов. Каждая игра относится к одной категории и может получать отзывы с числовыми оценками от зарегистрированных пользователей.

## Основные сущности
- **Игра** — название, категория, год выпуска и методы расчёта среднего рейтинга по отзывам.
- **Категория** — название и краткое описание жанра игры (например, «Стратегия», «Семейная игра»).
- **Пользователь** — имя пользователя, который может оставлять отзывы.
- **Отзыв** — связующая сущность: объект игры, объект пользователя, числовая оценка и текст комментария.

## Основные функции

- поиск и сортировка игр;
- добавление отзыва с оценкой от 0 до 10;
- расчёт среднего рейтинга и текстовой метки качества;
- вывод карточки игры;
- загрузка и сохранение данных в JSON;
- обработка ошибочных данных пользователя.

## Классы ПР3

- `Category` — жанр игры;
- `Game` — игра, её категория и год выпуска;
- `User` — пользователь каталога;
- `Review` — отзыв с оценкой, который связывает объект `Game` с объектом `User`.

`Game` хранит объект `Category`. Объект `Review` напрямую хранит объект игры
в `review.game` и объект пользователя в `review.user`, а не их числовые ID.
В JSON-файле связи сохраняются как `game_id` и `user_id`, а при загрузке снова
восстанавливаются ссылки на экземпляры классов.

## Структура

```text
board_game_catalog/
├── main.py            # меню приложения
├── models/            # пакет классов предметной области
│   ├── category.py
│   ├── game.py
│   ├── user.py
│   └── review.py
├── categories.py      # операции с категориями
├── games.py           # поиск и сортировка игр
├── users.py           # операции с пользователями
├── reviews.py         # создание и проверка отзывов
├── storage.py         # JSON-загрузка и сохранение
├── data/              # данные каталога
└── tests/             # автоматические тесты
```

## Запуск и проверка

```powershell
venv\Scripts\activate
python main.py
pytest -v
flake8 .

```

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.

Если виртуальное окружение уже активировано, программу можно запускать командой
`python main.py`. Без активации можно использовать полный путь:
`.\venv\Scripts\python.exe main.py`.
